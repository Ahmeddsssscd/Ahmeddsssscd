## Waselli

Algeria's transportation platform. Building the software layer for how people and goods actually move here — not a template adapted from another market.

| Domain | Scope |
| :--- | :--- |
| Dispatch | Real-time ride matching, driver allocation, live tracking |
| Routing | Route optimization tuned to Algerian roads, traffic, and addressing |
| Fleet | Driver onboarding, operator dashboards, partner management |
| Payments | Transaction infrastructure built for local payment behaviour |

The hard problems here are not the ones a generic ride-hailing clone solves. Addressing is inconsistent, connectivity is uneven, and payment rails are their own engineering project. That is the interesting part.
